# Roadmap

This roadmap covers 16 October 2026 through at least 16 October 2027. The priorities for that year are:

- Preserve command authorization, receipt binding, queue cancellation and diagnostic redaction.
- Extend regression/fuzz evidence for Android input parsers and all CLI transport boundaries.
- Evaluate durable delivery and device acceptance separately from queue acknowledgement.

For all work, preserve compatibility, add failure-path regressions and document operational limits. Establish and test maintainer-access continuity when a real backup arrangement exists. These are plans, not delivered features or a promise of dates. Propose and discuss changes through GitHub issues and pull requests.

## Non-goals for this period

The project will not claim exactly-once durable delivery from a queue acknowledgement, bypass device authorization or update signatures, or promise compatibility with untested player/Android hardware.
