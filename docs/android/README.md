# Android devices

Setting up and maintaining the Android tablet and player builds that the
controller drives.

- [Android tablet: Plex strict kiosk and startup](../android-kiosk-setup.md) — the strict kiosk configuration and its startup behaviour.
- [Android OTA: ordinary players and the separate rooted agent](../android-ota.md) — how updates reach ordinary players and where the root agent differs.
- [Shared Android USB manager](../android-usb-manager.md) — the shared USB manager across connected Android devices.
- [Android USB maintenance with ADB](../android-adb.md) — device identification, installation and Android-level diagnosis.
- [Android local media and playback without a network](../android-offline-media.md) — Local videos over the Storage Access Framework, including the API 22 Fire variant.
- [Legacy Android recovery over USB](../android-usb-recovery.md) — the explicit ADB backend in `tools/android_usb_supervisor.py`.
