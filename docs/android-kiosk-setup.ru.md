Для выделенного планшета нужны три независимо проверенные настройки: очередь контента, строгая политика киоска OTT и автозапуск Android. Установка APK или проверка выключения экрана и возобновления не доказывает запуск после перезагрузки ОС.

## Идентификация и установка

1. Зафиксируйте физический планшет, alias/UUID OTT, alias USB-менеджера, серийный номер, модель, Android ID и SDK. Имена OTT и USB могут отличаться; не определяйте устройство по имени и не используйте токен другого планшета.
2. Выберите официальный вариант APK, совместимый с SDK, проверьте SHA-256 выпуска, идентичность пакета и подписи, установите через `install -r`. Сохраните данные плеера. Если USB принадлежит [общему менеджеру](android-usb-manager.md), используйте его; не запускайте конкурирующий сервер ADB или команды `adb` без явного выбора устройства.
3. Сопрягите плеер с его собственными реквизитами контроллера и проверьте `ott TABLET`. Загрузите нужный именованный пресет и выполните `ott TABLET load PRESET verify`. Пресеты домашней сети и localhost-пресет машины разработчика не взаимозаменяемы.

## Проверка Plex с планшета

```sh
ott TABLET plex libraries
ott TABLET plex library --preview 'LIBRARY NAME'
```

Проверьте ID библиотеки, название и число элементов. Успешный запрос с компьютера администратора не доказывает доступ с планшета. При ошибках проверьте на планшете сохранённый адрес, маршрутизацию, поддержку TLS и реквизиты. Предпочитайте действительный HTTPS-адрес сервера. Если старой прошивке нужен HTTP в частной LAN, ограничьте изменение этой установкой, запишите, что токены и медиа передаются по LAN без шифрования, и не переписывайте общий пресет и не отключайте проверку сертификатов глобально. Никогда не публикуйте токены и частные URL медиа в диагностике или документации.

В новых плеерах с возможностью `categories` в `caps` Plex открывает все видео без обязательного выбора папок. Используйте `ott TABLET categories` и `ott TABLET category all`; см. [категории медиа](cli.md#media-categories-and-stable-video-selection). Приведённые ниже шаги выбора папок относятся к явно указанной старой версии плеера.

Смена адреса сервера Plex очищает выбранные корни библиотек. Выберите провайдера **Plex**, откройте **Plex settings → Folders**, отметьте строку нужной библиотеки (не только **Browse folders**), нажмите **Ok**, затем **Save and open library**. В плеере `1.1.58-beta.19` одни реквизиты сервера могут открыть выбор папок, пока `ready` остаётся false; завершите выбор до команд очереди. Не подменяйте провайдера на M3U лишь ради `ready: true`: очередь Plex может играть там, но `kiosk on --strict` может сохранить ожидающую политику M3U без привязанного медиа. Она не блокирует и не восстанавливает очередь Plex.

## Запуск и блокировка очереди

```sh
ott TABLET kiosk off
ott TABLET plex shuffle 'LIBRARY NAME'
ott TABLET plex status
ott TABLET debug --engine
# Continue only after the intended queue is playing.
ott TABLET kiosk on --strict
ott TABLET plex status
ott TABLET kiosk status
ott TABLET debug --engine
```

Для упорядоченной очереди используйте `plex library 'LIBRARY NAME'` вместо `plex shuffle`. Shuffle выбирает порядок один раз; киоск повторяет его. Подтвердите нужные элементы, `enabled: true`, `strict: true` и политику, привязанную к нужной очереди Plex. Политика `waiting` без канала или медиа не означает принятого киоска. Сделайте не менее двух замеров с растущей позицией/счётчиком кадров и осмотрите экран. Подтверждения или надписи `playing` без прогресса недостаточно. Проверьте естественный переход после конца элемента; если полный цикл проверить непрактично, явно запишите это ограничение.

Строгий киоск управляет интерфейсом плеера. Это не регистрация Android device owner и не доказательство блокировки Home, Recents, уведомлений и Settings. Сохраните системный лаунчер и способ обслуживания в присутствии оператора.

## Отдельное включение автозапуска

Соберите и проверьте [OTT Home 0.2.0](../native/android-home/README.md), сохранив существующий ключ подписи для обновлений. Установите `play.ott.home` рядом с `play.ott.foss`. Откройте `play.ott.home/.StartupActivity` и включите **Start OTT after reboot**. По умолчанию настройка выключена. Она не меняет официальный бинарный файл плеера, подпись OTA, данные профилей или назначение кнопки Home.

На прошивке с выбором Home можно дополнительно выбрать **OTT Home → Always**. Если выбора нет (включая проверенную старую прошивку Fire), разрешение запуска после загрузки работает независимо. Ранее настроенные установки default Home сохраняют поведение. Для полного отката отключите оба механизма.

`recover_on_boot` общего USB-менеджера — третий независимый механизм: ему нужны NAS и USB-кабель, он обрабатывает только новую загрузку и не перезапускает постоянно упавшее приложение. Он не заменяет автономный запуск. При его проверке оставьте политику восстановления выключенной, чтобы она не скрыла отсутствие запуска сопутствующим приложением. Соблюдайте защиту экрана блокировки; при запросе разблокируйте штатно.

## Приёмка и передача

Сохраняйте доказательства приватно, без реквизитов в публичных квитанциях:

- Версии APK, хеши, соответствие физического устройства идентификаторам OTT/USB и выбранный пресет.
- Библиотека Plex, число/порядок элементов, строгая политика и исходное воспроизведение с прогрессом.
- Boot ID до и после настоящей перезагрузки ОС; затем `sys.boot_completed=1`.
- Отсутствие ручного запуска плеера или USB-восстановления между перезагрузкой и наблюдением.
- Активность OTT на переднем плане, восстановление связи с контроллером, очереди/строгой политики и продвижение воспроизведения. Результат `requested` загрузочного приёмника означает только отправку запроса.
- Отдельный тест кнопки питания: экран погашен, звук остановлен, штатная разблокировка и возобновление.
- Точные ограничения: обязательная защищённая разблокировка, USB-восстановление, непроверенные способы выхода из киоска физическими кнопками, ошибки потоков или нехватка памяти. Не называйте такие случаи полностью принятыми.

Перед передачей следующего планшета повторите этот список проверок, а не копируйте успех предыдущего устройства. Старым Fire может требоваться `hls.js` для M3U из-за падений встроенного HLS производителя; это не доказывает устойчивость воспроизведения Plex.

## Обслуживание и откат

```sh
ott TABLET kiosk off
```

Откройте **OTT Startup**, отключите **Start OTT after reboot** и восстановите исходный выбор Home, если он менялся. При необходимости удалите только `play.ott.home` через проверенный USB-транспорт; сохраните `play.ott.foss` и его данные. Отключение автозапуска не меняет очередь и не снимает киоск автоматически.
