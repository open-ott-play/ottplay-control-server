# OTT-play controller documentation

The self-hosted server that delivers remote commands to OTT-play players, the
terminal CLI that drives it, and the optional features built on top of the two.

- [Documentation wiki home](wiki/Home.md) — the versioned wiki navigation source and the list of guides it points at.
- [Controller, CLI and API](guide/README.md) — the command routes, the terminal client and the protocols built on them.
- [Player features](players/README.md) — commands that need a matching player capability, and their diagnostics.
- [Televisions and devices](devices/README.md) — direct control of a television or a bound device.
- [Android devices](android/README.md) — kiosk setup, OTA updates and USB management for Android tablets and players.
- [Operations](operations/README.md) — deployment, the development and release toolchain, and the monitoring runbook.
- [Favorites design contracts](design/README.md) — global Favorites, its recovery paths and provider configuration.

## Wiki overview

The [wiki home](wiki/Home.md) lists the reading order for a first setup: start a
player, connect from the terminal, then follow the guide for the feature you need.
