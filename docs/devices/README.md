# Televisions and devices

Direct control of a television or a bound device, separate from controlling the
OttPlay page itself.

- [Direct LG television control](../television.md) — the `tv` command for system volume, power state and other set-level actions.
- [Shut down a supported device](../device-power.md) — `ott PLAYER shutdown` through an ADB binding or a managed controller.
- [Television shell shortcuts](../shell-shortcuts.md) — the `coco` and `cocop` shortcuts that wake, open and play.
